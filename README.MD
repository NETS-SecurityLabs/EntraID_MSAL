# MSAL Hands-On Lab

Microsoft Authentication Library(MSAL)을 통해 Entra ID 인증을 적용하는 실습입니다.

## 사전 준비(실습 코드 다운로드)

Codespace에서 실습 예제 파일을 다운로드하는 절차입니다.

- **(주의)** 진행과정에서 복사 붙여넣기를 위한 클립보드 사용 요청 시 반드시 허용해야 진행이 가능합니다.
![alt text](/srcs/image-1.png)

<br>

* 만약 클립보드 붙여넣기 팝업 창을 실수로 닫은 경우 브라우저의 주소창 영역에서 클립보드 사용을 허용할 수 있습니다.
![alt text](/srcs/image-5.png)


1. 화면 하단의 터미널 탭 선택 후 예제 파일 다운로드 명령어를 입력합니다.
```cmd
git clone https://github.com/NETS-SecurityLabs/EntraID_MSAL.git
```
![alt text](/srcs/image-2.png)


2. 파일이 정상적으로 다운로드 되면 아래와 같이 EntraID_MSAL 폴더가 생성됩니다.
![alt text](/srcs/image-3.png)

이 후 EntraID_MSAL > EntraID.ASP.NETCore.Board 순으로 폴더를 확장하여 HOL.md 파일을 확인합니다.
해당 파일에서 마우스 우클릭 후 **미리 보기 열기**를 선택합니다.

![alt text](/srcs/image-4.png)
